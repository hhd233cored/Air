# Notes from a quiet corner

这是一个从 Markdown 文件读取的文章示例。你可以直接替换这个文件的内容，页面会把它渲染成文章正文。

## 留一点空间

好的页面不需要把每一寸空间都填满。留白可以让文字慢下来，也让读者更容易记住真正重要的部分。

> 让内容先呼吸，再开始表达。

目前支持常用的 Markdown 结构：标题、段落、引用、列表、链接、行内代码、代码块和图片。

- 将文章内容放在 `public/articles/first-note.md`
- 使用 Markdown 语法组织正文
- 如果需要图片，可以使用标准 Markdown 图片语法

## 下一步

后续可以把文章列表、文章封面和文章元信息也改成由 Markdown 文件统一管理。
