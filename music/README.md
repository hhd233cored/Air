# 本地音乐

将音频文件放在此目录或其子目录中，并在 `playlist.json` 的 `tracks` 数组添加歌曲索引。歌曲的标题、作者、专辑、时长和封面都从音频文件的内嵌元数据中读取。

示例：

```json
{
  "tracks": [
    {
      "id": "song-01",
      "name": "歌曲名称"
    }
  ]
}
```

后端会按以下顺序定位音频文件：

1. 音频文件名（不含扩展名）等于 `id`；
2. 音频文件名（不含扩展名）等于 `name`；
3. 音频内嵌标题等于 `name`。

例如 `id` 为 `song-01` 时，可以放置 `music/songs/song-01.mp3`。封面需要嵌入音频文件，不再单独读取图片文件。

支持的音频格式：`.mp3`、`.m4a`、`.aac`、`.wav`、`.ogg`、`.flac`、`.webm`。

如果修改了歌单文件，后端会自动重新读取；新增或替换音频文件后建议重启后端。
